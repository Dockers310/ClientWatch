# ClientWatch 2.2.10

## Исправление смены статуса из меню игрока

- `Shift+ПКМ` по любому обнаруженному моду теперь действительно меняет его статус.
- Если мод ещё не был добавлен через «Запрошенные моды», первый `Shift+ПКМ` автоматически создаёт локальное правило со статусом `Запрещён`.
- Следующие `Shift+ПКМ` переключают `Запрещён → Требует проверки → Разрешён → Старая разрешённая версия → Запрещён`.
- В меню игрока вместо сообщения «не добавлен — менять статус нечего» теперь показывается действие добавления.
- Для локальных правил отключено принудительное превращение `Разрешён` в `Требует проверки`: правило применяется ко всем версиям обнаруженного мода.

## Исправление названий

- Если после старого сохранения в `watchlist.yml` в качестве названия оказался технический ключ вида `modrinth:XeEZ3fK2`, ClientWatch при совпадении с реально обнаруженным модом восстанавливает нормальное отображаемое имя из профиля игрока и сохраняет его.
