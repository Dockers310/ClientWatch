# ClientWatch 2.2.2

- Добавлен режим «все версии проекта»: например, Freecam можно сразу сделать запрещённым для любой версии, даже если конкретный файл 26.2 ещё не найден в каталоге.
- Сохранена история заходов: текущий заход помечается «Сейчас в игре», предыдущие заходы остаются в HistoryGui и profiles.yml.
- Проверка во время текущей игры отключена: автоматическая проверка выполняется только при входе; /afc check, повторная проверка и массовая перепроверка больше не запускают проверку.
- Companion отправляет SHA-512 и SHA-1 каждого найденного JAR.
- Companion отправляет версию Minecraft, Fabric Loader и безопасно определённое имя лаунчера. Сырые аргументы запуска на сервер не отправляются.
- Команда регистрируется именно как /afc; старые алиасы остаются.
- plugin.yml сохраняет folia-supported: true и используется Folia/Paper-совместимый планировщик.
