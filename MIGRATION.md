# Обновление с предыдущего ClientWatch

1. Остановите сервер.
2. Замените `ClientWatch.jar` новой сборкой.
3. Не удаляйте существующие `config.yml`, `profiles.yml`, `flags.yml`, `access.yml` и другие файлы данных.
4. Новый список проверяемых модификаций хранится отдельно в `watchlist.yml`.
5. После запуска старые данные остаются на месте.
6. Изменение списка через GUI или `/afc reload` сразу пересчитывает классификацию уже полученных отчётов онлайн-игроков.

Основная команда теперь официально указана как `/afc`; старые алиасы `cwatch`, `antifreecam` и `clientwatch` сохранены для совместимости.
