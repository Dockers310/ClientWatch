# ClientWatch 2.2.9

## GUI
- Добавлено `Shift+ПКМ` по моду в меню профиля игрока для смены статуса записи в «Запрошенных модах».
- В подсказке предмета теперь явно показано текущее сочетание для смены статуса.
- Исправлена обработка `Shift+ПКМ` в списке «Запрошенных модов»: сначала проверяется точный `SHIFT_RIGHT`, чтобы он не воспринимался как обычный ПКМ.
- Асинхронный поиск/загрузка больше не переоткрывает старое меню поверх другого GUI и не перехватывает последующие клики.

## ClientWatch Companion
- Запрос списка модов теперь повторяется до 3 раз с одним и тем же nonce.
- В консоль добавлена запись об отправке запроса и предупреждение, если Companion не ответил после всех попыток.
- Сохраняется проверка nonce, поэтому старые/чужие ответы не принимаются.

## Сохранение названий
- Старые записи `watchlist.yml`, у которых вместо названия сохранился ключ вида `modrinth:...` или `curseforge:...`, при загрузке пытаются восстановить человекочитаемое имя из исходного запроса/slug и сохраняются уже с исправленным названием.

## Диагностика
- Для обмена с Fabric Companion сервер продолжает использовать обычный Paper/Bukkit plugin channel.
