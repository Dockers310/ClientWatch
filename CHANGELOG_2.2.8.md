# ClientWatch 2.2.8

## Исправление цветов модов
- Меню модов игрока теперь классифицирует не только `cw:` записи Companion, но и старые записи `fp:`/`ch:`.
- Незапрошенные моды больше не показываются лаймовым красителем только потому, что они присутствуют в последнем заходе.
- Один мод, который был получен несколькими источниками (`cw:`, `fp:`, `ch:`), объединяется в одну запись; приоритет имеет Companion.
- Краситель берётся строго из `WatchStatus`: красный / жёлтый / лаймовый / серый. Незапрошенные — фиолетовые.

## Отображение игрока с Companion
- В заголовке меню модов ник игрока теперь тоже отображается золотым и жирным, если Companion уже прислал отчёт.
- В меню «Игроки» сохранено золотое жирное выделение ника и добавлена единая классификация модов.

## Клики GUI
- Обычные левые клики для открытия/отметки используют `ClickType.isLeftClick()`, чтобы не терять корректные варианты клиентских кликов.
- Обычные правые клики для смены статуса используют `ClickType.isRightClick()`.
