# ClientWatch 2.2.11

Плагин для Paper 26.2 / Folia (Java 25): контроль клиентских модов игроков с помощью watchlist (Modrinth + CurseForge) и пассивного Fabric-мода **ClientWatch Companion**.

Полная история изменений — в [CHANGELOG.md](CHANGELOG.md).

## Возможности

### Watchlist модов
- Поиск проектов на Modrinth и CurseForge по названию или ID для Fabric 26.2.
- Карточки проектов, файлы 26.2, SHA-512, SHA-1 / CurseForge fingerprint и человекочитаемые зависимости.
- Режим «все версии проекта»: мод можно запретить для любой версии, даже если конкретный файл ещё не найден в каталоге.
- Список хранится отдельно в `watchlist.yml`. Старые `profiles.yml`, `flags.yml`, доступы и настройки не удаляются.

### Статусы и цвета
| Статус | Краситель |
|---|---|
| Запрещён | красный |
| Требует проверки | жёлтый |
| Разрешён | лаймовый |
| Старая разрешённая версия (Legacy) | серый |
| Не запрошен / не сопоставлен | фиолетовый |

- Статус определяется по совпавшему проекту (Fabric ID, slug, project-id, название), а не по глобальному SHA-сопоставлению.
- Несовпавший проверочный код (SHA-512) при совпадении названия/ID переводит мод в «требует проверки».
- Одна запись объединяет данные из разных источников (`cw:`, `fp:`, `ch:`); приоритет у Companion.
- Изменение watchlist сразу переклассифицирует уже онлайн-игроков, без перезахода.

### Меню игрока
- Список модов игрока, лаунчер («Похоже на») и версия игры (по протоколу через PacketEvents).
- **Shift+ПКМ** по моду меняет статус:
  - если мода ещё нет в «Запрошенных модах», первый `Shift+ПКМ` создаёт локальное правило со статусом `Запрещён`;
  - далее по кругу: `Запрещён → Требует проверки → Разрешён → Старая разрешённая версия → Запрещён`.
- Локальные правила применяются ко всем версиям обнаруженного мода.
- Игроки с Companion отображаются золотым жирным ником, меткой `[CW]` и свечением предмета.
- В карточке файла отдельно подписаны SHA-512, SHA-1 и CurseForge fingerprint.
- История заходов сохраняется; текущий заход помечается «Сейчас в игре».

### ClientWatch Companion (Fabric 26.2)
- Полностью пассивный: без команд, меню, клавиш и настроек — только отвечает на запрос сервера.
- Передаёт полный список Fabric-модов, SHA-512 и SHA-1 локальных JAR, версию Minecraft, Fabric Loader и безопасно определённое имя лаунчера. Сырые аргументы запуска не отправляются.
- Запрос повторяется до 3 раз с одним nonce; чужие и устаревшие ответы отбрасываются. Если ответа нет, в консоль пишется предупреждение.
- Ответ уходит обычным vanilla `ServerboundCustomPayloadPacket`, совместимым с Paper/Bukkit plugin channel.
- Полный список модов доступен только пользователям с доступом к плагину.

### Проверка
- Автоматическая проверка выполняется при входе игрока (ограничена 5 секундами).
- Во время игры автоматическая проверка не запускается; доступна явная перепроверка одного игрока.

### Paper + Folia
- `folia-supported: true`, `api-version: 26.2`.
- Планировщик на `EntityScheduler`, `GlobalRegionScheduler` и `AsyncScheduler`; общие коллекции потокобезопасны, I/O не блокирует регион.

## Команды
| Команда | Описание |
|---|---|
| `/afc` | Главное меню |
| `/afc watch` | Запросы / запрещённые / разрешённые модификации |
| `/afc mods <ник>` | Профиль и моды игрока |
| `/afc check <ник>` | Перепроверка одного онлайн-игрока (обычная проверка + запрос Companion) |
| `/afc access add <ник> <menu\|pumpkin\|notify>` | Выдать доступ |
| `/afc pumpkin on\|off <ник>` | Тыква для игрока |
| `/afc reload` | Перезагрузка конфигурации и watchlist с немедленной переклассификацией |

Старые алиасы команды сохранены.

## Права и доступ
- `clientwatch.menu` — доступ к меню.
- `clientwatch.notify` — уведомления.
- `clientwatch.pumpkin` — тыква (отдельно; с ним `/afc pumpkin` работает без доступа ко всему меню).
- В меню «Доступ»: `Shift+ПКМ` переключает доступ к тыкве, `Shift+ЛКМ` снимает именно его.
- `Dok_Si` — встроенный владелец с полными правами; удалить его через GUI, команды или `access.yml` нельзя.

## Настройка

### CurseForge
Для поиска через CurseForge укажите ключ разработчика в `config.yml`:

```yaml
platforms:
  curseforge:
    api-key: "..."
```

### Моды-читы и алерты персоналу
Моды из `mods-db.yml` по умолчанию попадают только в профиль игрока. Чтобы мод подсвечивался красным и слал алерт персоналу, перенесите его в `config.yml` → `mods:` с `category: "cheat"`.

### Файлы данных
`profiles.yml`, `flags.yml`, `access.yml`, `pumpkin.yml`, `watchlist.yml`, `mods-db.yml`, `config.yml`.
