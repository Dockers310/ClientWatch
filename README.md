# ClientWatch 2.2.9

Обновление для Paper 26.2 / Java 25.

## Новое
- Watchlist Modrinth + CurseForge для Fabric 26.2.
- Поиск по названию/ID, карточки проектов, файлы 26.2, SHA-512, SHA-1/fingerprint и человекочитаемые зависимости.
- Статусы: запрещён, требует проверки, разрешён, Legacy-исключение.
- Несовпавший SHA-512 при совпадении названия/ID автоматически попадает в «требует проверки». Не сопоставленный мод отображается фиолетовым.
- `ClientWatch мод полной проверки` для Fabric 26.2 передаёт по запросу сервера полный список Fabric-модов и SHA-512 локальных JAR, когда источник мода доступен как файл.
- Shift+ПКМ по моду в профиле игрока меняет статус записи в «Запрошенных модах» (для менеджера).
- Буферные/асинхронные ответы поиска больше не перехватывают другое открытое меню.
- Улучшен обмен с ClientWatch Companion: запрос повторяется до 3 раз с одним nonce.
- Для Companion ответ отправляется обычным vanilla `ServerboundCustomPayloadPacket`, что совместимо с Paper/Bukkit plugin channel.
- Игроки с мод полной проверки отображаются золотым жирным именем.
- Изменение watchlist переклассифицирует уже онлайн-игроков без перезахода. `/afc reload` перечитывает watchlist.yml.
- Автоматическая проверка при входе ограничена 5 секундами.
- Старые `profiles.yml`, `flags.yml`, доступы и настройки не удаляются; новый список хранится отдельно в `watchlist.yml`.

## Команды
- `/afc` — главное меню.
- `/afc watch` — запросы/запрещённые/разрешённые модификации.
- `/afc check <ник>` — обычная проверка + запрос мод полной проверки.
- `/afc reload` — перезагрузка конфигурации и watchlist с немедленной переклассификацией.

## CurseForge
Для поиска через CurseForge укажи `platforms.curseforge.api-key` в `config.yml`. CurseForge API требует ключ разработчика.


## Версия 2.2.6

Исправлены цвета модов в профиле игрока, улучшено выделение игроков с ClientWatch Companion, уточнены подписи SHA-512/SHA-1 и усилена обработка кликов GUI.

- Основная команда: `/afc`.
- Права доступа выдаются отдельно: `/afc access add <ник> menu`, `/afc access add <ник> pumpkin`, `/afc access add <ник> notify`.
- `Dok_Si` — встроенный владелец с полными правами, его нельзя удалить.
- Перепроверка одного онлайн-игрока: `/afc check <ник>` или кнопка «Перепроверить этого игрока» в меню игрока.
- История заходов и текущий заход сохраняются.
- Поддерживаются Paper 26.2 и Folia.
