# ClientWatch 2.1.5

Собрано поверх твоих правок (ускоренная проверка при входе, отдельный доступ `pumpkin`,
короткая команда `/afc p`) - все они сохранены без изменений. Добавлено:

## Больше модов в базе (mods-db.yml)

Добавлены в базу известных модов (не читы, не срабатывания - только профиль игрока,
как Sodium/JEI и остальные из базы):

- Accurate Block Placement (Reborn)
- Gamma Utils
- Inventory Profiles Next
- Shield Status (walksy)
- Auto Clicker (pro.mikey / ErrorMikey)
- Simple AutoClicker (sansrus)
- AutoSwap (Nikrecs)
- XPlus Autofish

Не нашлось надёжного способа определения (в jar нет ни одного lang-файла и ни одной
клавиши) для **ShieldFixes** и **Combat Hitboxes** - комментарий прямо над этим местом
в `mods-db.yml`.

Часть добавленных модов (автокликеры, автозаброс удочки, автосвап) дают игровое
преимущество - по умолчанию они всё равно только в профиле (без уведомления персонала).
Если нужно, чтобы какой-то из них подсвечивался красным как читерский клиент и слал алерт
стаффу - перенеси его в `config.yml` → `mods:` с `category: "cheat"` (или скажи мне, какие
именно - сделаю).

## Лаунчер и версия игры в профиле

- Профиль игрока (`/afc mods <ник>`, список игроков, история заходов, список срабатываний
  Freecam) теперь показывает:
  - **Похоже на:** лаунчер/клиент, угаданный по client brand (Lunar Client, Badlion,
    Feather/Dawn, LabyMod, Polar, Hyperium, Vivecraft, известные читерские клиенты и т.д. -
    см. `dev/antifreecam/util/LauncherUtil.java`). Не 100%-гарантия - client brand
    присылает сам клиент, его можно подделать, но большинство лаунчеров этого не делает.
  - **Версия игры:** определяется по протоколу подключения через PacketEvents
    (`ClientVersion` из хендшейка) - это надёжнее, подделать штатными средствами клиента
    нельзя.
- Оба поля сохраняются в `profiles.yml` и попадают в историю каждого захода.
